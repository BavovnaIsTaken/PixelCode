# iOS розгортання - Резюме реалізації

## Огляд

Реалізована функціональність розгортання iOS білку на локальне пристрій через Wi-Fi мережу. Ця функція дозволяє розробникам швидко тестувати зміни на реальних пристроях без необхідності кабелю USB.

## Структура реалізації

### 1. Сервіс (`lib/services/ios_deploy_service.dart`)

Основний бізнес-логіка для управління процесом розгортання:

- **`discoverDevices()`** - Автоматичний пошук iOS пристроїв в локальній мережі
  - Використовує ARP команду для пошуку Apple пристроїв
  - Резервний механізм: сканування локальної мережи через ping

- **`buildIOSApp()`** - Побудова iOS білку
  - Команда: `flutter build ios --release`
  - Реальний час лог вивід
  - Пошук побудованого білку в стандартних директоріях

- **`deployToDevice()`** - Встановлення на пристрій через мережу
  - Команда: `ios-deploy --bundle=<path> --id=<ip>`
  - Потребує ios-deploy: `brew install ios-deploy`
  - Реальний час статус оновлення

- **`buildAndDeploy()`** - Повний цикл: побудова + встановлення

- **`checkDependencies()`** - Перевірка наявності необхідних інструментів

### 2. UI Діалог (`lib/widgets/settings/ios_deploy_dialog.dart`)

Користувацький інтерфейс для взаємодії з процесом розгортання:

**Функціональність:**
- Поле введення IP-адреси пристрою
- Автоматичний пошук пристроїв в мережі
- Список знайдених пристроїв з можливістю швидкого вибору
- Лог область з реальним часом вивід (300px висота)
- Прогрес-бар під час розгортання
- Статус-сповіщення (помилка/успіх)
- Відключення кнопок під час операції

**Дизайн:**
- Темна тема, відповідає стилю додатку
- Акцентний колір: `Color(0xFF00C0D1)` (ціан)
- Адаптивна ширина: 600px
- Максимальна висота: 800px

### 3. Інтеграція в UI

**Два місця запуску:**

1. **Заголовок (Title Bar)** - `/lib/screens/hub/hub_screen.dart`
   - Кнопка з іконкою `Icons.phone_iphone`

2. **Налаштування (Settings)** - `/lib/widgets/settings/settings_dialog.dart`
   - Секція "Розгортання на пристрій"

   - Описова довідка про передумови

## Передумови для користувачів

### Обов'язкові інструменти:

1. **ios-deploy**
   ```bash
   brew install ios-deploy
   ```

2. **Flutter SDK** - вже встановлено в проекті

3. **Wi-Fi мережа** - обидва пристрої повинні бути в одній мережі

### Процес підготовки iPhone:

1. Підключити до Wi-Fi мережі
2. Отримати IP-адресу (Налаштування → Wi-Fi → назва мережі)
3. Ввести IP в діалог розгортання

## Обробка помилок

Розташування обробки помилок:

- **Перевірка залежностей** - спеціальна перевірка інструментів
- **Перевірка файлів** - вивірка існування білку перед встановленням
- **Timeout** - обмеження часу для операцій
- **Процес обробка** - читання stderr з виводом помилок
- **Користувацькі повідомлення** - зрозумілі українські повідомлення про помилки

## Особливості

### Автоматичний пошук пристроїв

Реалізовано трьохрівневий механізм:

1. **ARP Scan** - Пошук за MAC адресою Apple пристроїв
   ```bash
   arp -a | grep -i apple
   ```

2. **Network Scan** - Сканування локальної мережи (до 20 адрес)
   - Отримання локального IP
   - Ping на типові адреси
   - Обмежений таймаут для швидкості

3. **Manual Input** - Користувач може ввести IP вручну

### Реальний час прогрес

- Потоковий вивід stderr/stdout
- Фільтрація порожніх рядків
- Маркування помилок
- Історія логів до 1000 рядків

### Перевірка залежностей

```dart
final (hasIOSDeploy, hasFlutter) = await _service.checkDependencies();
```

Окремі статуси для кожного інструменту з рекомендаціями установки.

## Технічні деталі

### Версія Dart

Код сумісний з Dart 3.0+ завдяки:
- Dart 3 records: `(String name, String ip)`
- Null safety
- Extensions methods

### Асинхронность

Операції виконуються асинхронно:
- Побудова білку може тривати 2-5 хвилин
- Встановлення через мережу може тривати 1-3 хвилини
- Не блокує UI завдяки Future.wait і Process.start

### Безпека

- Без виконання команди shell (використовується Process.run)
- Валідація IP адреси перед використанням
- Перевірка існування файлів перед операціями
