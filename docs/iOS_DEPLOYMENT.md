# iOS розгортання через локальну мережу

Цей документ описує як встановити iOS білк на локальне пристрій через Wi-Fi мережу.

## Передумови

Для розгортання iOS білку на локальне пристрій через мережу необхідно встановити наступні інструменти:

### 1. ios-deploy

`ios-deploy` - це інструмент, який дозволяє встановлювати додатки на iOS пристрої через мережу.

Встановлення:

```bash
brew install ios-deploy
```

Перевірка встановлення:

```bash
ios-deploy --version
```

### 2. Flutter SDK

Переконайтесь, що Flutter встановлено та доступно в PATH:

```bash
flutter --version
```

## Локальна мережа

Обидва пристрої (Mac, що розробляє, та iPhone, на який встановлюється) повинні бути в одній Wi-Fi мережі.

### Визначення IP-адреси iPhone

1. Відкрийте **Налаштування** на iPhone
2. Перейдіть до **Wi-Fi**
3. Натисніть на назву мережі, до якої підключено пристрій
4. Запишіть IP-адресу (наприклад: 192.168.1.100)

## Використання

### Через UI

1. Відкрийте додаток PixelCode
2. Натисніть на кнопку **Розгорнути на iOS** у верхній панелі (іконка з телефоном)
   - Альтернативно: Налаштування → Розгортання на пристрій → Розгорнути на iOS

3. У діалозі введіть IP-адресу вашого iPhone (наприклад: 192.168.1.100)

4. Натисніть **Розгорнути**

Процес включає:
- Побудову iOS білку (`flutter build ios --release`)
- Встановлення білку на пристрій через `ios-deploy`
- Запуск додатку

### Прогрес

Лог операцій у реальному часі відображається у діалозі. Кожна команда записується з назвою та всіма деталями.

## Можливі помилки

### "ios-deploy не встановлено"

**Рішення:**
```bash
brew install ios-deploy
```

### "flutter не встановлено"

**Рішення:** Переконайтесь, що Flutter знаходиться в PATH:
```bash
which flutter
```

Якщо flutter не знайдена, додайте його в PATH у `~/.zshrc` або `~/.bash_profile`:
```bash
export PATH="$PATH:[path-to-flutter]/bin"
```

### "Помилка при побудові білку"

Перевірте логи в діалозі. Типові причини:
- Проблеми з кодуванням (синтаксичні помилки)
- Відсутність необхідних залежностей
- Проблеми з сертифікатами підписання

Спробуйте побудувати білк вручну:
```bash
flutter build ios --release
```

### "Помилка при встановленні"

Типові причини:
- iPhone не знаходиться в одній мережі з Mac
- IP-адреса невірна
- Прев'язка вер. може мати проблеми

Перевірте:
1. Чи обидва пристрої в одній Wi-Fi мережі
2. Чи IP-адреса правильна
3. Чи дозволено розробку на iPhone (Налаштування → Розробник)

## Автоматичний пошук пристроїв

Діалог намагається автоматично пошукати доступні iOS пристрої в мережі, використовуючи:
1. ARP (Address Resolution Protocol)
2. Мережеве сканування (обмежене)

Якщо автоматичний пошук не спрацює, введіть IP-адресу вручну.

## Структура проекту

- `lib/services/ios_deploy_service.dart` - сервіс для управління побудовою та встановленням
- `lib/widgets/settings/ios_deploy_dialog.dart` - UI діалог для взаємодії
- `lib/screens/hub/hub_screen.dart` - містить кнопку запуску в заголовку

## Примітки

- Побудова iOS білку може тривати кілька хвилин залежно від розміру проекту
- Встановлення через мережу може бути повільнішим ніж через USB
- Переконайтесь, що брандмауер не блокує з'єднання між пристроями

## Альтернативні способи

### Розгортання через USB (Xcode)

```bash
flutter run -d <device-id>
```

### Побудова без встановлення

```bash
flutter build ios --release
```

Білк буде в `build/ios/iphoneos/Runner.app`
