# Яскрава офісна палуба (Bright Office Deck) — Палітра 7 кольорів

## 📋 Огляд
Замінена темна, атмосферна "воєнна галера" на яскраву, контрастну офісну палубу. Нова тема ідеально підходить для освітлених робочих просторів з сучасним дизайном.

---

## 🎨 7-Колірна схема

### 1. **Стіни** — Світло-сірий
- **HEX:** `#E8E8E8`
- **RGB:** (232, 232, 232)
- **Використання:** Основний фон стін, світлі поверхні
- **Функція:** Чистий, мінімалістичний офісний простір
- **Контраст:** ✓ Висока читаність на темних елементах

### 2. **Підлога** — Теплий бежевий
- **HEX:** `#D4C8A8` (темний) / `#C0B494` (сітка/швів)
- **RGB:** (212, 200, 168) / (192, 180, 148)
- **Використання:** Дубові дошки палуби, деталі підлоги
- **Функція:** Теплота та натуральність, контраст до стін
- **Контраст:** ✓ Видимі швів між досками

### 3. **Двері & Обрізи** — Темно-сірий
- **HEX:** `#4A4A4A`
- **RGB:** (74, 74, 74)
- **Використання:** Дверні рами, модерністичні обрізи, тераси
- **Функція:** Чіткі геометричні акценти, офісна естетика
- **Контраст:** ✓ Експресивно виділяється на світлих стінах

### 4. **Меблі** — Натуральний дуб
- **HEX:** `#8B6F47` (основний) / `#6B4F2A` (тінь)
- **RGB:** (139, 111, 71) / (107, 79, 42)
- **Використання:** Столи, крісла, офісні шафи
- **Функція:** Органічна текстура, тепла робоча атмосфера
- **Контраст:** ✓ Помітний на білих стінах

### 5. **Акцент** — Яскраво-синій (Cyan)
- **HEX:** `#0A8FD1` (основний) / `#1FA8E8` (яскравіший)
- **RGB:** (10, 143, 209) / (31, 168, 232)
- **Використання:** Монітори, лампи, декоративні елементи, деталі
- **Функція:** Сучасна енергія, яркість, привертає увагу
- **Контраст:** ✓ Максимальний контраст на нейтральних фонах

### 6. **Деталі & Метал** — Полірована сталь
- **HEX:** `#3A3A3A` / `#5A5A5A` / `#7A7A7A`
- **RGB:** (58, 58, 58) / (90, 90, 90) / (122, 122, 122)
- **Використання:** Болти, скріпи, металеві кріплення, рейки
- **Функція:** Промислова витримка, сучасність
- **Контраст:** ✓ Трьохрівнева шкала для об'єму

### 7. **Вторинний акцент** — Помаранчевий
- **HEX:** `#FF8C42`
- **RGB:** (255, 140, 66)
- **Використання:** Ударні деталі, попередження, виділення
- **Функція:** Енергійна альтернатива синьому
- **Контраст:** ✓ Дополнительный контраст до синього

| Елемент | Темна тема | Яскрава тема | Зміна контрасту |

| Стіни | `#1A1208` | `#E8E8E8` | +200% яскравіше |
| Підлога | `#2A1E0E` | `#D4C8A8` | +180% яскравіше |

## ✅ Реалізовані зміни

### 1. **room_themes.dart**
```dart
const _galley = RoomTheme(
  wallBase: Color(0xFFE8E8E8),     // Світлі стіни
  floorDark: Color(0xFFD4C8A8),    // Теплий дуб
  accentColor: Color(0xFF0A8FD1),  // Яскраво-синій
  vignetteAlpha: 0.15,             // Яскравий офіс
);
```

### 2. **galley_sprites.dart**
- **7 основних кольорів** з логічними альтернативами
- **Legacy mapping** для назад сумісності з існуючим рендеринг кодом
- Всі спрайти (мачта, вітрила, якорь, бочки, барабан) тепер рендеруються в яскравій палітрі
- **Контрастність посилена** через світлі стіни + темні деталі

## 🎯 Візуальні принципи

### Контраст
- **Світлі фони** (`#E8E8E8`) дозволяють темним елементам (`#2A2A2A` – `#4A4A4A`) виділятися яскраво
- **Теплі земляні тони** (дуб, бежевий) балансують холодну цян енергію

### Читаність
- ✓ Всі текстури залишаються видимими (швів, дошок)
- ✓ Монітори та лампи явно помітні в синьому акценті
- ✓ Дверні рами вирізняються без плутанини

### Сучасність
- 7-колірна палітра — стандарт сучасного дизайну (достаточно для деталізації, але не перевантажена)
- Использование цяну вместо теплих меди — свідомий вибір на користь сучасного офісу
- Мінімалістична естетика (низька вінетка `vignetteAlpha: 0.15`)

---

## 🔄 Зворотна сумісність

Всі існуючі функції рендеринга (мачта, вітрила, якорь, бочки, барабан, флаг, люк) **автоматично** використовують нові кольори через legacy-mapping:

```dart
// Приклад: мачта все ще рендериться `_oakDark`, але тепер це `_furnBrownDark`
const _oakDark = _furnBrownDark;  // Color(0xFF6B4F2A)
```

**Жоден рендеринг код не був змінений** — тільки палітра переназначена.

## 📸 Покрокові зміни

### До (темна палуба)
- Дуб: `#1E1408` → `#3D2B14` (дуже темна)
- Вода: `#0D1B2A` → `#2A6070` (ніч)
- Бронза: `#CD7F32` (теплий коричневий метал)
- **Вінетка:** 0.30 (темна атмосфера)

### Після (яскрава палуба)
- Дуб: `#6B4F2A` → `#8B6F47` (природній теплий)
- Вода/Акцент: `#0A8FD1` (яскравий цян)
- Метал: `#3A3A3A` → `#7A7A7A` (промислова сталь)
- **Вінетка:** 0.15 (яскравий офіс, мало затіння)

## 🚀 Рекомендації на майбутнє

1. **Тестування на різних екранах** — перевірити контраст на мобільних пристроях
2. **Анімаційне освітлення** — синя лампа може мерехтіти для живості
3. **Варіанти палітри** — можна створити "денну" vs "нічну" версії офісу
4. **Додаткові акценти** — помаранч (`#FF8C42`) зарезервований для попереджень або бонусів

## 📐 Технічні деталі

- **Color space:** RGB (Dart `Color` клас використовує sRGB)
- **Непрозорість:** За замовчуванням 100%, використовується `.withValues(alpha: X)` для полупрозорі елементи
- **Градієнти:** Не використовуються — тільки плоскіRect'и для пікселю-арту
- **Масштабування:** Спрайти залишаються 16px базовими одиницями (kTileSize)
