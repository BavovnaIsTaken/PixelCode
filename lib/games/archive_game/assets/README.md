# Асети гри про архівацію

Повний набір піксельарту для освітної гри про архівацію файлів. Розраховано на школярів 5-7 класів.

## Вміст

### 1. Іконки файлів (`file_icons.dart`)
- **Текстовий файл** — синій файл з лініями
- **Зображення** — файл з гірськими піками та сонцем
- **Музика** — файл з музичними нотами
- **Відео** — файл з кнопкою Play

Кожна іконка:
- Має вибір (жовта рамка)
- Масштабується легко
- Чіткі контури для дітей

### 2. Папка та архів (`folder_archive.dart`)
- **FolderPainter** — піксельарт папка жовтого кольору
- **ArchivePainter** — архів (ZIP) рожевого кольору з блискавкою
- **ContainerPainter** — контейнер для файлів (синій)

Кожен елемент:
- Інтерактивна (показує стан selected)
- Має 3D ефект
- Легко розпізнається

### 3. Кнопки (`buttons.dart`)
- **Архівувати** (зелена)
- **Розпакувати** (синя)
- **Далі** (оранжева)
- **Повернути** (червона)

Особливості:
- Піксельарт стиль
- Натиск та наведення (hover)
- 3D ефект (тінь)
- Стан вимкнено (disabled)

### 4. Фони рівнів (`level_backgrounds.dart`)
- **Рівень 1** — сонячний день (синій-зелений градієнт)
- **Рівень 2** — хмарний день (сіро-синій)
- **Рівень 3** — грозовий (фіолетовий-чорний)

Кожен фон має:
- Декоративні елементи (хмари, молнії)
- Анімацію частинок
- Адаптивну розмірність

### 5. Анімації архівації (`archive_animations.dart`)

#### FileToArchiveAnimation
Файл входить у архів:
- Зміщення в бік архіву
- Зменшення розміру
- Легке обертання
- Тривалість: 1.5 сек

#### CompressionAnimation
Архів стискається:
- Пульсація масштабу
- Хвилі сухо
- Повтор

#### ExtractionAnimation
Файли виходять з архіву:
- Розлітаються в різні боки
- По кругу
- Від центру

## Використання

### Приклад 1: Показ іконки файла
```dart
CustomPaint(
  painter: FileIconPainter(
    fileType: FileType.image,
    isSelected: false,
  ),
  size: const Size(64, 64),
)
```

### Приклад 2: Кнопка архівації
```dart
ArchiveGameButton(
  label: 'Архівувати',
  buttonType: GameButtonType.archive,
  onPressed: () {
    print('Archive clicked!');
  },
)
```

### Приклад 3: Фон рівня
```dart
LevelBackground(
  levelNumber: 1,
  child: Column(
    children: [
      // Вміст рівня
    ],
  ),
)
```

### Приклад 4: Анімація файла в архів
```dart
FileToArchiveAnimation(
  fileLabel: 'photo.png',
  duration: const Duration(milliseconds: 1500),
  onComplete: () {
    print('File archived!');
  },
)
```

### Приклад 5: Анімація розпакування
```dart
ExtractionAnimation(
  fileCount: 4,
  duration: const Duration(seconds: 2),
)
```

## Рекомендації для використання

1. **На мобільних пристроях**: файли 48x48 px, папка/архів 64x64 px
2. **На десктопі**: масштабуйте в 1.5-2x
3. **Для друку**: перетворіть в PNG з 300 DPI
4. **Анімації**: вимикайте на слабких пристроях
5. **Контраст**: всі елементи розраховані на матові екрани

## Доступність

- ✅ Великі елементи (не менше 48x48 px)
- ✅ Яскраві, контрастні кольори
- ✅ Чіткі контури (2px)
- ✅ Без поганих шрифтів
- ✅ Однозначні іконки

## Апдейти та розширення

Готові до:
- Додавання нових типів файлів
- Більше рівнів (поточно 3)
- Спеціальних анімацій (збір, впорядкування)
- Мобільної оптимізації
